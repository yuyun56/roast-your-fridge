One line roasting a fridge: it runs all day and all night, and still the only thing in it with any culture is the yogurt. The entry is the single line in entry.txt (99 of 200 characters); main.ts is a small guard that validates it and hands it in.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# prints the line, its length and the budget left, and writes out/entry.txt
```
